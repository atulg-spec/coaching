i Where do I find my Cloudflare API credentials? ▼

1. Cloudflare Account ID: Log in to dash.cloudflare.com. Select any domain or look at the right sidebar of your dashboard home where your Account ID (a 32-character hex string) is displayed.

2. Cloudflare API Token: In Cloudflare, navigate to My Profile → API Tokens → click Create Token. Choose Create Custom Token, set permission: Account → Workers AI → Read / Edit, and generate your token.

3. Models: Cloudflare Workers AI offers fast open models like @cf/meta/llama-3.1-8b-instruct, @cf/meta/llama-3.2-3b-instruct, and @cf/mistral/mistral-7b-instruct-v0.1.
